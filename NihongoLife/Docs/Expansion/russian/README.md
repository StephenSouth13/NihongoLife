# Russian (ТРКИ / TORFL) module — DRAFT, cần người bản ngữ duyệt
Cấu trúc theo 6 cấp chứng chỉ: ТЭУ(A1) · ТБУ(A2) · ТРКИ-1(B1) · ТРКИ-2(B2) · ТРКИ-3(C1) · ТРКИ-4(C2).
Mỗi cấp 5 phần thi: Лексика.Грамматика · Чтение · Аудирование · Письмо · Говорение; đạt ≥66% mỗi phần.
- levels/<cefr>.json: ngữ pháp (5 câu, giải thích tiếng Việt), đọc (1 bài + câu hỏi), nghe (2 bài + câu hỏi).
- listening/*.txt: kịch bản nghe; *.mp3 sinh bằng TTS (ru-RU-SvetlanaNeural) nếu có — chưa phải giọng thật.
- manifest.json: danh mục.
Chưa nối vào game (theo AGENTS.md: mở rộng chưa có trong game nằm ở Docs/Expansion/). Còn thiếu: Письмо/Говорение đề mẫu, ngân hàng câu lớn hơn (mỗi cấp mới ~9 câu), duyệt bản ngữ.
