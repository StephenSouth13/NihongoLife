# Business Analyst Pack — NihongoLife

Cập nhật: 2026-10-10

Thư mục này tập trung tài liệu phục vụ Business Analyst: mô tả sản phẩm, phạm vi, luồng nghiệp vụ/người dùng, kiến trúc, dữ liệu, sequence/state và quy trình bàn giao. Các ảnh được sao chép từ bộ tài liệu gốc để BA có thể sử dụng độc lập mà không làm thay đổi nguồn.

## Cấu trúc

| Thư mục | Nội dung |
|---|---|
| `01_Product_Overview` | Tầm nhìn, đối tượng, giá trị, phạm vi, gameplay và tiêu chí thành công |
| `02_Business_and_User_Flows` | Core loop, bản đồ thế giới và use case |
| `03_System_Architecture` | Kiến trúc phân lớp và class diagram |
| `04_Data_Model` | ERD dịch vụ Supabase |
| `05_Sequence_and_State` | Luồng hội thoại, mini-game và state thể lực |
| `06_Delivery_and_Operations` | Deployment và workflow phát triển |
