MENU GALLERY (About popup screenshots)

Drop PNG or JPG screenshots into this folder. They appear automatically in the main-menu
"Ve toi / About me" popup, sorted by file name:

  01_Menu.png
  02_Sushi restaurant.png
  03_Station.png

Rules
- The name (without the leading number and extension) becomes the caption, e.g. "Sushi restaurant".
- For a Vietnamese / English / Japanese caption, add an entry to Resources/Menu/menu_about.asset
  under "Captions" with the file name (without extension) in "Texture Name".
- Use 16:9 images around 1920 x 1080 (or smaller). Larger files only increase the web download size.
- Texture Type "Default" is fine; no Sprite settings needed.
