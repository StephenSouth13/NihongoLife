# Exam media drop folder

Put local authoring files here temporarily while preparing an exam. Do not commit large media files to
Git and do not reference this folder from a published WebGL build. Convert masters to optimized MP3/MP4,
upload them to the media CDN, then put only the final URL, checksum, start time, duration and aspect
ratio in `manifest.json` or the remote exam record.

Recommended names:

```text
listening_hotel_01.mp3
listening_hotel_01.mp4
```
