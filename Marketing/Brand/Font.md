# Font

Ảnh, PDF và lịch Excel dùng **Montserrat** (Regular, Medium, SemiBold, Bold, ExtraBold).

- Tác giả: The Montserrat Project Authors
- Nguồn file: https://github.com/JulietaUla/Montserrat
- Giấy phép: SIL Open Font License 1.1, nguyên văn trong `fonts/OFL.txt`
- Montserrat có Latin mở rộng, đủ dấu tiếng Việt

Dòng `日本語ライフ` trên ảnh dùng **Noto Sans JP** bản cắt chỉ còn các chữ đó, để khỏi nhét cả bộ CJK vào git.

- Giấy phép: SIL Open Font License, `fonts/OFL-NotoSansJP.txt`
- Không gõ câu tiếng Nhật khác bằng hai file subset này. Thiếu glyph sẽ thành ô vuông.

Excel chỉ ghi tên font Montserrat. Máy nào chưa cài thì phần mềm đổi font dự phòng. PDF nhúng Montserrat lúc in từ Chrome.
